### [v0.2.0](https://github.com/championswimmer/pi-subagent-manager/releases/tag/v0.2.0) — Minor release (2026-10-01)

#### Highlights

- Configure hierarchical delegation with `maxLevels` (default **3**, including the main conversation as L1), `maxConcurrent` (16), and `maxThreads` (64).
- Load isolated global and trusted-project settings from `subagent-manager/settings.json`; reload them with `/agents reload`.
- Guide root and delegating child agents to launch independent siblings with `wait:false` before waiting. Offline SDK coverage proves two L2 coordinators can launch four overlapping L3 agents.
- Count independent roots as L2 so they cannot bypass the level limit. Existing retained sessions are not cancelled when limits change.
- Include the previously unreleased resumable-subthread improvements and themed activity-pill colors.

#### Configuration

Global: `~/.pi/agent/subagent-manager/settings.json` (or your configured pi agent directory).
Trusted project override: `.pi/agent/subagent-manager/settings.json`.

```json
{"maxLevels":3,"maxConcurrent":16,"maxThreads":64}
```

This extension does not consume `.pi/subagents.json` from `@tintinweb/pi-subagents`. Read-only agent types without delegation tools remain read-only; use a delegating type for L2 coordinators.

#### Verification

- 103 offline tests passing, including nested-parallel SDK execution and settings reload.
- TypeScript check and npm package dry run passing.
