### Research-tool contract for architect

The current child runtime does not inherit MCP/parent tools. Architect must consume a **supplied research packet** or use **authorized shell retrieval**, including an Exa CLI/API only if it is actually installed/configured and authorized. Do not hardcode unavailable Exa MCP tool names into child instructions, promise nonexistent tool access, or embed credentials. If retrieval is unavailable, explicitly state that limitation and ask for parent-supplied sources. Parent-side codemode Exa access can produce the packet: URLs, dates, fetched passages, contradictions, and unresolved questions. Model ability and retrieval availability are separate decisions.

### Five versus six responsibilities

**Prefer architect + researcher:** architectural decisions naturally depend on requirements, documentation, constraints, and alternatives. Keep the writer separate so evidence collection is not optimized for compelling narrative. Risk: confirmation bias toward a preferred design; mitigate with competing hypotheses and GPT-only review.

**Writer + researcher alternative:** reduces handoffs and is useful for short, low-stakes editorial work. It couples prose preference with source selection and unsupported interpolation. If used, require research first, a frozen evidence packet, composition second, and separate citation verification. These are workflow recommendations, not leaderboard findings.

## Findings

1. **Arena measures human preference, not factuality.** The Oct 2 creative-writing index lists `gemini-4-argon-high` 1519±19 (preliminary; 1,097 votes), `claude-opus-5.5-high` 1516±20 (1,058), `claude-fable-5-high` 1503±8 (8,182), and `claude-opus-4-6-high` 1501±6 (14,085). Intervals overlap substantially. Writing/literature/language similarly lists Argon 1522±17 and Opus 5.5 1519±17. These category-specific blind preferences are not citation or editorial fact-check scores. `high` denotes a tested configuration, not necessarily an API name. [Creative writing](https://arena.ai/leaderboard/text/creative-writing), [Writing/literature/language](https://arena.ai/leaderboard/text/industry-writing-and-literature-and-language), [Overall text](https://arena.ai/leaderboard/text). **Original-child provenance:** readable fetches exposed little table content; numbers initially came from Exa's source-linked index rather than an independently captured table. **Parent verification addendum, 2026-10-03:** Exa MCP full-page fetch subsequently recovered the primary creative-writing table and confirmed Argon **1519±19** (1,097 votes), Opus **1516±20** (1,058), Fable **1503±8**, and Muse Spark 1.3 max **1459±12**. This resolves creative-table recovery, not the overall or writing/literature/language table gap; these are live source checks, not benchmark reproductions. Small vote counts and overlapping intervals still preclude a clear Argon-over-Opus win.

2. **EQ-Bench supplies a different writing signal.** Its official JS data (`v=1.0.91`), fetched for this research, reports GPT-6 Astra Elo 2173.3, Claude Fable 5.1 2162.0, Claude Opus 5 2132.6, GPT-6 Sol 2124.7, and Claude Opus 5.5 2050.1. Muse Spark 1.3 is 1905.9; Gemini 3.8 Flash 1747.9. These are LLM-judged short-form outputs, not human preference or source fidelity. Some entries have a `*` prefix whose meaning was not verified; treat those provisionally. The asset has no verified evaluation date, so it is a live snapshot rather than an archived Oct 3 guarantee. Elo is relative to the comparison pool and is not comparable to Arena's scale or a percentage. [Leaderboard](https://eqbench.com/creative_writing.html), [Actual data](https://eqbench.com/creative_writing.js?v=1.0.91). Short-form success does not establish long-form editorial revision quality.

3. **Gemini is a strong large-context candidate; availability and retrieval remain constraints.** Google's Sep 30 announcement verifies **Gemini 4 Argon**, including creative writing and long-horizon knowledge work, but describes phased rollout to trusted defenders/testers before broader access. Its Oct 2 recap describes a 1M-token window. Do not invent an API identifier from the Arena name or assume immediate access. [Announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/), [Oct 2 recap](https://blog.google/innovation-and-ai/technology/ai/google-ai-updates-september-2026/). Google's documentation explicitly warns that multi-needle retrieval may be substantially worse than single-needle retrieval: window capacity is not retrieval accuracy or source fidelity. [Long-context docs](https://ai.google.dev/gemini-api/docs/long-context).

4. **Muse Spark 1.3 is verified; strongest evidence here concerns engineering.** Meta's Sep 2 release emphasizes long-horizon agentic/coding work. The official page lists 1M context and separate standard/contributor tiers; Vercel independently confirms integration the same day. The parent-fetched primary Arena creative-writing table places its max configuration at **1459±12**, below the leading candidates; EQ-Bench is competitive but not leading. No current citation-fidelity result was verified. [Meta release](https://research.meta.ai/blog/introducing-muse-spark-1-3), [Official model page](https://developer.meta.com/ai/models/muse-spark/), [Vercel](https://vercel.com/changelog/muse-spark-1-3-now-available-on-ai-gateway), [Arena mirror](https://www.benchleader.com/benchmarks/lmarena_text_creative). Contributor changes data-use terms and available reasoning effort: **max is Standard-only**. Equivalent performance at shared efforts was not established. Do not silently use Contributor for confidential work. [Official reasoning docs](https://ai.developer.meta.com/docs/reasoning/). We interpreted the user's `must-spark-1.3` as Muse Spark 1.3; this is an interpretation, not a verified alias. Standard `muse-spark-1.3` and Contributor `muse-spark-1.3-contributor` are distinct tier identifiers. [Official model identities](https://ai.developer.meta.com/docs/models/).

Coverage/configuration differences prevent declaring a current global winner. ## Source fidelity and Exa: acceptance criteria

Exa supplies discovery/retrieval; the model chooses searches, reconciles sources, and writes claims. An agent-product score cannot be transferred automatically to an Exa-equipped raw model. Links alone do not prove claim support.

Evaluate suggestions with identical available retrieval tools, budgets, prompts, and sources:

- Writing: blind voice preference, stock-phrase avoidance, style-guide adherence, revision fidelity, long-form consistency.
- Research: factual correctness, supported-citation precision, material-claim coverage, primary-source proportion, correct dates/versions, contradictions/abstention, long-document retrieval recall.
- Preserve URL, publication date where available, retrieval timestamp, and quotation/span for each material claim. Check citations against fetched text, not snippets, and recheck after composition.
- For child agents without retrieval, use identical supplied evidence packets and evaluate synthesis separately from discovery.
- Test representative tasks and inspect failures, latency, and cost before changing defaults. No source found establishes a universal writing-plus-citation winner.
